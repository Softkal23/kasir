# WarkopKu APK

Cangkang Android (Capacitor) yang membuka situs WarkopKu.

1. Edit `capacitor.config.json`: ganti `https://GANTI-DOMAINMU.com` dengan alamat situs (HTTPS).
2. Unggah semua isi folder ini ke repositori GitHub (branch `main`).
3. Tab Actions > Build APK > Run workflow.
4. Unduh `WarkopKu-apk` di bagian Artifacts, ekstrak, lalu pasang `app-debug.apk` di HP.
